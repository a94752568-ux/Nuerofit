# Plugin `symbols.speed`

**Dominio:** atención / velocidad (ámbar `#FFB84C`)  
**Input:** tap

## Mecánica

1. Se muestra un símbolo objetivo.
2. Cuadrícula de opciones debajo.
3. Toca el que coincide.
4. 20 trials; más opciones y distractores según nivel 1–8.

Hub → **Velocidad de Símbolos** → Empezar.
